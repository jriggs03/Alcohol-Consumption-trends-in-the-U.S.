# U.S. Health & Alcohol Classification

Models health survey and drinking patterns.

**Team course project for STAT 551: Statistical Machine Learning at Cal Poly.** Includes James Riggs's analysis and the teammate analysis preserved as `Jose.qmd`; these are credited as team work, not a solo project.

## What it does

Cleans coded BRFSS responses, explores health and alcohol-related variables, and fits classification models. The teammate analysis also uses U.S. Chronic Disease Indicators.

## Run

Open the `.qmd` files in RStudio with Quarto. Install their declared R packages, obtain the source BRFSS/USCDI datasets independently, and update data paths to your local files. Render with Quarto or run the code chunks in order.

Source only: survey extracts, generated HTML, and caches are excluded. Original data paths are course-era paths and need adjustment. The private original repository is retained; this public repository is the curated portfolio version. No medical or causal claims are made.
